슬라이드 자동 생성

포털에 로그인해 사용자 페이지의 대시보드 목록에서 '슬라이드' 메뉴를 선택하고 '새로 만들기 → 새 슬라이드 생성'을 누르면, 좌측 채팅 패널에서 일반 AI 챗봇처럼 대화로 슬라이드를 요청할 수 있습니다.

만드는 방법 — 대화로 처음부터, 또는 있는 파일로

'새로 만들기'를 누르면 세 가지 방식으로 시작할 수 있습니다.

  • 새 슬라이드 생성 — 빈 슬라이드에서 시작해 AI와 대화하며 채워갑니다.
  • PPTX 파일 업로드 — 이미 갖고 있는 PPTX를 그대로 편집 가능한 슬라이드로 변환합니다.
  • 화면 업로드 — 직접 만든 HTML 파일을 그대로 올려 대시보드 화면으로 씁니다.

이렇게 만든 슬라이드와 대시보드는 모두 같은 '대시보드' 목록에 모여, '내 대시보드' 탭에서 한 번에 확인하거나 '공유받은 대시보드' 탭에서 다른 사람이 공유한 것을 받아볼 수 있습니다.

생성 진행 상황 확인

슬라이드가 만들어지는 동안 좌측 채팅 패널에 어떤 작업이 진행되는지 실시간 체크리스트로 표시됩니다 — 제목 설정, 보조 스킬 위임(예: "고객문의 데이터 분석" 완료), 아트 디렉션 설정, 페이지별 생성까지 단계별로 확인할 수 있습니다. 참고한 원본 자료도 카드 형태로 함께 표시되어, 클릭하면 바로 원문을 확인할 수 있습니다.

완성 후 직접 편집

자동 생성된 슬라이드는 캔버스 에디터에서 바로 손볼 수 있습니다.

  • 템플릿·폰트(기본값 Pretendard)·배경색을 페이지 단위 또는 전체 슬라이드에 일괄 적용할 수 있습니다.
  • 텍스트·목록·표·차트·이미지·도형·선 등을 블록 단위로 추가·편집합니다.
  • 이미지는 직접 업로드하거나 AI로 생성해, 자산 라이브러리에서 바로 불러다 쓸 수 있습니다.

공유와 내보내기

완성한 슬라이드는 화면 비율(16:9 등)을 설정해 발표 모드로 바로 띄우거나, PDF·PPTX로 다운로드할 수 있습니다. 변경 사항은 모두 자동 저장됩니다.

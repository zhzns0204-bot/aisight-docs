::: faq
#### 로컬 파일을 AI가 읽는 기술은 이미 있지 않나요? 이게 왜 다른가요?
기술 자체는 이미 있지만, 회사 보안 정책 때문에 실무자가 그대로 쓰지 못하는 경우가 많습니다. 웹 기반 AI 도구는 허용해도 로컬 파일 접근은 막아둔 회사가 많아서, 결국 파일을 하나씩 업로드하는 걸 반복하게 됩니다. aisight 데스크탑은 회사 보안 기준에 맞게 설계돼 있어, 폴더 경로 한 줄이면 되고 업로드라는 단계 자체가 없습니다.

#### 폴더 안에 파일이 많고 형식도 제각각이면 어떻게 되나요?
상관없습니다. "이 폴더 안에 있는 CS 문의 파일들 전부 읽어서 월별 트렌드 정리해줘"처럼 요청하면 폴더 안 파일을 형식·개수와 무관하게 하나씩 열어 확인하고, 흩어져 있던 데이터를 표 하나로 정리해줍니다.

#### 결과를 보고 더 파고들 수 있나요?
네. 나온 결과 위에서 대화하듯 이어서 물어볼 수 있습니다. "문의량이 갑자기 늘어난 달이 있으면 원인도 같이 짚어줘"라고 하면, 예를 들어 특정 달에 로그인 오류와 계정 관리 문의가 급증해 전체 증가분의 상당 부분을 차지했다는 식으로 원인을 짚어줍니다. 다음에는 폴더 경로만 바꿔서 같은 질문을 재사용할 수 있습니다.

#### 브라우저도 직접 조작하나요?
네. 스킬을 설정해두면, 채팅창에 프롬프트를 입력하는 것만으로 브라우저 창이 스스로 열리고 로그인·검색·클릭·페이지 이동까지 순서대로 진행합니다.

#### 브라우저 자동화는 실제로 어디에 쓰나요?
예를 들어 "최신 영상 10개의 주제를 요약하고 키워드 3개로 추려서, 조회수 높은 영상 3개씩 분석하고 차기 영상 주제 3가지 추천해줘"라고 하면, 유튜브 채널에 직접 들어가 최근 영상들을 분석해 어떤 키워드·제목 방식이 조회수를 끌었는지 짚어주고 다음 주제까지 추천합니다. 이어서 "그 주제로 대본까지 뽑아줘"라고 하면 제목·썸네일 카피·타임코드별 연출과 대사까지 표로 정리해줍니다.

::: faq
#### 데이터는 어디에 저장되나요?
문서 DB(컬렉션)와, 사용자별 개인 설정을 담는 저장소(KV)를 그대로 씁니다. 따로 DB를 구축할 필요가 없습니다.

#### 이미지나 PDF 같은 파일 첨부는 어떻게 하나요?
첨부파일 업로드·관리 기능이 기본 제공됩니다.

#### 로그인 기능을 직접 만들어야 하나요?
아니요. 별도 인증 시스템 없이, 플랫폼에 로그인한 사용자 정보를 그대로 씁니다.

#### 문서마다 다르게 권한을 걸 수 있나요?
네. 문서 단위로 "나만 보기 / 로그인한 전원 보기 / 앱 소유자만 보기" 등 세분화된 권한을 설정할 수 있습니다.

#### 알림창 같은 UI도 직접 만들어야 하나요?
아니요, 표준 알림(토스트) 컴포넌트가 제공됩니다.
:::

#### 쿼리가 실패하면 어떻게 되나요?
원인을 스스로 파악해 최대 5~10회까지 자동으로 재시도합니다. 그래도 안 되면 실패로 표시되고, 이 이력은 이후 스킬을 개선하는 데 쓰입니다.

#### 답변이 예전에 쓰던 Tableau 수치랑 다르게 나오면요?
AI가 원인을 분석해 설명해 줍니다. 필터 조건이나 계산 기준 차이처럼 흔한 원인이라면 바로 짚어 줍니다.

#### 대시보드는 항상 최신 데이터인가요?
DB에 연결된 대시보드는 새로고침할 때마다 항상 최신 수치를 보여줍니다. 반면 엑셀을 올려 만든 대시보드는 새로고침이 되지 않으니, 최신 데이터가 계속 필요하다면 DB 연결을 이용하세요.

#### 대시보드 HTML 파일을 다운로드해서 팀원에게 보내도 데이터가 새지 않나요?
안전합니다. HTML을 만드는 시점에는 데이터가 코드에 들어가지 않고, 실제로 화면에 띄우는 시점에 쿼리가 실행되어 데이터가 채워집니다. 파일만 갖고 있어서는 안의 수치를 볼 수 없습니다.

#### 엑셀 파일은 어떤 형식까지 되나요?
XLS·XLSX·XLSB를 지원합니다. XLSX가 가장 안정적으로 처리되고, XLS는 오래된 포맷이라 처리 속도가 느립니다.

#### 제가 만든 대시보드나 쓰는 스킬을 다른 사람도 볼 수 있나요?
데이터소스·스킬 단위로 사용자별 접근 권한이 걸려 있어, 권한이 없는 사람에게는 보이지 않습니다.

#### 직접 만든 HTML 파일을 대시보드로 올릴 수도 있나요?
네. 대시보드 목록의 '새로 만들기 → 화면 업로드'에서 HTML 파일을 직접 올릴 수 있습니다. 다만 보통은 Agent와 대화해서 만드는 쪽이 더 간단합니다.

::: faq
#### 슬라이드 주제를 정확히 모르겠으면 어떻게 하나요?
주제가 불명확하면 AI가 발표 대상(예: 임원·경영진), 핵심 목적(예: KPI 점검), 디자인 스타일 선호, AI 이미지 생성 여부 같은 선택형 질문을 몇 가지 먼저 던집니다. 답만 골라도 방향이 잡힙니다.

#### 슬라이드에 들어갈 데이터는 제가 직접 붙여넣어야 하나요?
아니요. 주제에 맞는 보조 스킬(예: 고객문의 분석 스킬)을 고르면, 그 스킬이 해당 DB를 조회해 관련 데이터를 자동으로 가져옵니다. 파일을 업로드하거나 내용을 따로 설명하지 않아도 됩니다.

#### 회사 데이터를 쓰려면 AI를 따로 학습시켜야 하나요?
아니요. 별도의 파인튜닝 없이, 회사에 이미 저장된 데이터를 그대로 활용합니다.

#### 결과물이 실제 데이터 기반인가요, 아니면 그럴듯하게 지어낸 건가요?
설문에 답하고 기다리면 실제 사내 데이터를 기반으로 슬라이드가 자동 완성됩니다. 예를 들어 CS 문의 데이터로 임원 보고용 슬라이드를 바로 만들 수 있습니다.

#### 이미 갖고 있는 PPTX 파일이 있으면 처음부터 다시 만들어야 하나요?
아니요. 대시보드 목록의 '새로 만들기 → PPTX 파일 업로드'를 선택하면 기존 PPTX가 그대로 편집 가능한 슬라이드로 변환됩니다.

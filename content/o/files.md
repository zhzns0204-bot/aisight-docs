- 소용량 데이터는 AI 컨텍스트에 직접 삽입합니다.
- 대용량 데이터는 시트별 컬럼 헤더만 참조해 필요한 내용만 DB에 적재한 뒤 조회합니다.
- 상위 1만 건까지 읽어 데이터 유형을 자체 분석한 뒤 질의응답 방식을 결정합니다.

| 포맷 | 처리 특성 |
| --- | --- |
| `XLS` | 구형 포맷, 처리 속도가 느립니다. |
| `XLSX` | 최적으로 지원되는 포맷입니다. |
| `XLSB` | 대용량 바이너리, 처리 성능이 양호합니다. |

- **API 연동** — 자연어로 외부 API 데이터를 조회하는 기능으로, 현재 더미 API로 검증 중이며 정식 연동을 준비하고 있습니다.
- **로그·쿼리 모니터링** — 실시간 로그·쿼리 모니터링과 감사(audit) 목적의 쿼리 추적을 제공하며, 실행된 쿼리가 엑셀 기반인지 DB 기반인지 구분해 확인할 수 있습니다.
- **잔존 데이터 확인** — 채팅을 삭제해도 쿼리·첨부파일이 남을 수 있어, 별도 모니터링 후 관리자가 직접 확인·삭제해야 합니다.
- **백그라운드 작업** — 통계 동기화 같은 백그라운드 서버 작업도 모니터링 대상입니다.

### 화면 구성 — 3개 탭

| 탭 | 역할 |
| --- | --- |
| 내용 | 제목·본문 작성. 리치 텍스트 에디터로 제목 스타일, 굵게·기울임·밑줄·취소선, 색상, 목록, 인용, 코드, 정렬, 링크, 표 삽입을 지원합니다. |
| 설정 | 갱신 주기, 버전이 바뀌었을 때 재동의를 요구할지, 동의를 거부하면 서비스 이용을 막을지, 관리자는 예외로 둘지를 정합니다. |
| 로그 | 사용자별 동의 이력을 조회합니다. |

### 서약서마다 다르게 설정할 수 있는 것

- **제목·본문** — 서약서마다 자유롭게 작성합니다.
- **서명 시 요구 정보** — 이름만 받을지, 이름과 아이디를 함께 받을지 서약서별로 다르게 정할 수 있습니다.
- **서명란 위치** — 왼쪽·중앙·오른쪽 정렬 중 선택합니다.
- **동의 거부 시 정책** — 거부하면 서비스 이용을 막는 필수형과, 거부해도 계속 쓸 수 있는 선택형을 모두 지원합니다.

### 실시간 미리보기

'미리보기' 버튼을 누르면 사용자에게 실제로 노출될 화면을 그대로 확인할 수 있습니다. 제목 → 본문 → 서약 문구("본인은 위 서약서의 내용을 충분히 숙지하였으며, 이를 성실히 준수할 것을 서약합니다") → 날짜 자동 표시 → 성명 입력(서명) → '동의합니다'/'동의하지 않습니다' 버튼 순서로 구성됩니다.

::: callout
label: 본인 확인 로직
로그인한 사용자의 실제 이름과 입력한 성명이 일치해야 동의가 완료 처리됩니다.
:::

### 사용자 화면에서는 이렇게 동작합니다

- 서약서가 활성화돼 있으면 로그인 직후 팝업으로 노출됩니다.
- '동의하지 않습니다'를 선택하면 자동으로 로그아웃됩니다.
- 한 번 동의를 완료하면, 이후 재접속에서는 다시 노출되지 않습니다.

### 버전 관리와 로그

저장할 때 '저장(새 버전)'을 누르면 기존 버전을 덮어쓰지 않고 새 버전이 만들어집니다. 버전마다 수정 일자와 수정자 계정이 기록되고, 각 버전을 개별적으로 '보기'·'가져오기'(다운로드)할 수 있습니다 — 예를 들어 v1(최초 작성)부터 v2, v3(관리자 수정)까지 이력이 그대로 남습니다.

누가 어떤 버전에 언제 동의했는지도 별도 DB 조회 없이 관리자 화면(로그 탭)에서 바로 확인할 수 있습니다.

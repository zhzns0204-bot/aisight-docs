챗봇 창에 갇히지 않습니다. 지금 보고 있는 대시보드의 맥락을 인지하고, 화면을 직접 조작해 답의 근거를 눈앞에 보여줍니다.

- **화면 맥락 인지 · Zero-Click 드릴다운** — 현재 대시보드의 필터와 뷰 상태를 인지해 대화에 즉시 반영하고, 필터·탭을 일일이 클릭하지 않아도 말 한마디로 심층 데이터 화면으로 전환합니다.
- **스킬 기반 자율 분석 실행** — 질의 의도를 분류해 권한 범위 내 최적의 분석 스킬을 자동으로 고르고, 여러 스킬을 병렬로 호출해 매출·마케팅 등 교차 분석을 한 번에 끝냅니다.
- **Tableau 대시보드 임베드** — 전용 Extension으로 지금 쓰는 Tableau 대시보드에 그대로 탑재되어, 기존 분석 환경을 바꾸지 않고 해석 시간만 줄여줍니다.
